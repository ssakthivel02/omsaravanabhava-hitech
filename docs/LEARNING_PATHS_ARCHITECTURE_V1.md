# OmSaravanaBhava Hi-Tech — Guided Learning Paths Architecture V1

## Purpose

Turn the platform into a trustworthy Murugan learning environment, not merely a directory of pages. Learning paths must guide visitors from discovery to deeper source-aware study without inventing devotional content or using manipulative gamification.

## 1. Learning modes

Support distinct modes:

- **Discover** — first introduction to Murugan names/forms/works/temples.
- **Read** — canonical/source-aware reading.
- **Understand** — reviewed meaning/context separated from canonical text.
- **Explore** — relationships among works, temples, places and traditions.
- **Practice** — private/local devotional tools based only on governed material.
- **Verify** — inspect sources, variants, completeness and rights state.

## 2. Suggested starter paths

Create only when sufficient governed content exists.

### Path A — அறிமுகம் / Introduction to Murugan

Possible units:

1. names and epithets from governed records;
2. Vel symbolism from sourced editorial context;
3. six Arupadai Veedu identities;
4. major devotional works available in the corpus;
5. how OmSaravanaBhava distinguishes source, tradition and reflection.

### Path B — Six Abodes

For each abode:

- identity;
- official source;
- governed traditional/literary context;
- current verified visitor information when available;
- related works/verses only when source-linked;
- what remains pending.

### Path C — Thiruppugazh Study

Only after canonical bodies are publishable:

- canonical Tamil;
- source/edition;
- easy Tamil;
- transliteration;
- meaning/commentary;
- related temple/place where source-supported;
- textual variant notes.

### Path D — Sacred Works Library

Explain the identity, author/source, rights state and available layers of each governed work without implying missing text is present.

## 3. No fake progression

Do not use:

- coercive streaks;
- rankings;
- leaderboards;
- guilt/shame reminders;
- fabricated spiritual rewards;
- guaranteed benefit claims.

Progress can be local and descriptive:

- `Not started`
- `In progress`
- `Read`
- `Saved for later`

Completion is a learning convenience, not a spiritual score.

## 4. Source-first lesson structure

A lesson should distinguish:

1. `Canonical / Source Record`
2. `Plain Explanation`
3. `Context / Relationships`
4. `Sources`
5. `What remains uncertain or pending`

Generated AI reflection, if used later, must be visually separate and follow the AI trust contract.

## 5. Assessment / reflection

If quizzes are added, they should test factual/source-aware learning only.

Do not grade faith, devotion, spiritual worth or religious correctness of personal belief.

Good question types:

- identify an Arupadai Veedu;
- match a work to an author/source;
- distinguish canonical text from commentary;
- recognise verification/rights states;
- navigate to the underlying source.

## 6. Accessibility and reading comfort

Learning paths must work with:

- keyboard only;
- screen readers;
- 200% zoom;
- reduced motion;
- 320px mobile;
- Tamil-first typography;
- English interface parity when claimed.

No lesson requires hover, animation or audio to understand essential information.

## 7. Offline/local progress

Progress should be local-first by default and versioned for schema migration.

No account required.

Do not transmit study/practice history to analytics by default.

## 8. Deep linking

Every lesson/unit should deep-link to real underlying records rather than duplicate source content into a parallel lesson database without provenance.

Learning paths are orchestration over governed records, not a second uncontrolled content universe.

## 9. Editorial quality gate

A learning path can be public only when:

- every factual/canonical claim resolves to governed records;
- rights permit exposed text/media;
- missing content is not hidden by AI filler;
- lesson objectives are clear;
- Tamil reading quality is reviewed;
- accessibility and mobile flows pass.

## Product principle

The best learning experience should make visitors more capable of finding and understanding the underlying sources, not more dependent on opaque summaries.
