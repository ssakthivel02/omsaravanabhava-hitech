# Contributing — OmSaravanaBhava Hi-Tech

This repository is intentionally strict because it protects both engineering integrity and devotional-source integrity.

## Read first

1. `CURRENT_PROJECT_AUTHORITY.md`
2. `CLAUDE_CURRENT_OVERRIDE_R2.md`
3. `CLAUDE_R2_LATE_STAGE_ADDENDUM.md`
4. `release/R2_QUALITY_GATES.json`
5. `release/CONTENT_STATE_MODEL_V1.json`
6. `docs/SACRED_TECH_DESIGN_SYSTEM_V1.md`

## Branching

Do not develop application features directly on `main`.

Preferred active build branch:

`build/native-r6-flagship`

Use pull requests for promotion into `main`.

## Source isolation

Never import application/runtime code from:

- `ssakthivel02/OmSaravanaBhava` legacy application;
- KirthiVerse;
- RamaVerse;
- DivyaNexus;
- Kandan;
- SakthiAI/SaravanAI;
- OSB Training Academy;
- any unrelated donor project.

R6 is governed OmSaravanaBhava data/provenance evidence only.

## Devotional content

Never invent or silently rewrite canonical Tamil, mantra wording, Thiruppugazh, temple history, coordinates, timings, source citations, or audio provenance.

Keep canonical text, easy Tamil, transliteration, meaning and generated reflection as independent layers.

## UI / design

The design standard is Sacred-Tech: Murugan/Vel/Arupadai Veedu specific, Tamil-first, calm, cinematic, accessible and fast.

Do not introduce generic dashboard/card-grid UI, continuous particles, scroll-jacking, autoplay sound, or heavy hero media without measured justification.

## Engineering gates

Before PR promotion, run the exact candidate gates defined in `release/R2_QUALITY_GATES.json` and attach evidence. Missing mandatory evidence remains `PENDING/NO-GO`.

## Deployment

No production DNS/root-domain change is permitted without explicit owner approval after exact-head qualification.
